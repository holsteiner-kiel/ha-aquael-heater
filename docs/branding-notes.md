# Branding notes

The current 0.1.5 branding refresh is focused on the Aquael **Flow Heater BT** as an inline heater in the hose loop, not as a submerged stick heater.

Repository assets:

- `docs/banner.svg` - README banner using the inline flow heater concept.
- `docs/icon-flow.svg` - documentation/source SVG for the Flow Heater icon concept.
- `custom_components/aquael_heater/brand/icon-flow.svg` - source SVG next to the Home Assistant brand icon.

Home Assistant currently uses `custom_components/aquael_heater/brand/icon.png` for the local integration icon.
